## Definition of Agent Network

An **agent network** $(\mathcal{N})$ is a large-scale organization of multiple agent instances that collectively support the execution of a complex project $(P)$ composed of many tasks $(\mathcal{T}\_{P}=\{\tau\_1,\tau\_2,\ldots,\tau\_m\})$. The participating agents $(A\_i\in\mathcal{N})$ may differ in their roles $(r\_i)$, capabilities $(c\_i)$, responsibilities $(q\_i)$, available tools or resources, and relationships with other agents. Unlike a task-scale agent team, an agent network does not require all agents to participate in the same task or to communicate continuously with one another. Instead, different subsets of agents $(\mathcal{N}\_{\tau,t}\subseteq\mathcal{N})$ may become relevant to different tasks at different execution steps $(t)$, and their participation, coordination, and interaction patterns may change as the project progresses. Some agents may perform specialized tasks independently, some may coordinate across task boundaries, and some may temporarily form smaller collaborative configurations for particular tasks. The network therefore provides a broader organizational structure through which many agents, tasks, capabilities, and inter-agent relationships can be dynamically arranged to support the overall project objective.

## Conditions for an Agent Network to Hold 

An **agent network** $(\mathcal{N})$ should hold when a complex project $(P)$ requires or supports the organized participation of multiple agent instances across a collection of tasks $(\mathcal{T}\_{P})$, rather than concentrating all participating agents on a single task. The agents should have meaningful functional relationships within the broader project, such as differentiated roles, capabilities, responsibilities, task assignments, communication pathways, coordination dependencies, or resource-sharing relationships. It is not necessary for every agent to interact directly with every other agent, and different agents may remain inactive or irrelevant to particular tasks. Instead, task-specific subsets $(\mathcal{N}\_{\tau,t})$ may be selected, instantiated, activated, or reorganized according to the current project state $(S\_t)$, task requirements $(R\_{\tau,t})$, available information $(I\_t)$, environmental conditions $(E\_t)$, and relevant context $(C\_t)$. An agent network is therefore characterized by project-level scope, multiple participating agents distributed across multiple tasks, heterogeneous or differentiated agent functions, and a network of relationships through which agents or subsets of agents can be coordinated as project requirements evolve.

## Similarities Between Agent Team and Agent Network

Both an **agent team** $(\mathcal{A}\_{\tau})$ and an **agent network** $(\mathcal{N})$ organize multiple agent instances around a shared higher-level objective and allow individual agents to contribute through different roles, capabilities, subtasks, actions, or forms of interaction. In both structures, agent participation does not need to remain static: assignments, roles, communication relationships, and responsibilities may change according to task or project states, intermediate results, available information, environmental changes, and contextual conditions. Both can support communication, information exchange, coordination, review, critique, delegation, and iterative refinement, and both may allow multiple agents to work on different subtasks or on the same problem when redundancy, comparison, or alternative reasoning is useful. Their common foundation is therefore the organized use of multiple agent instances whose combined activities contribute to an objective that would otherwise be performed by one agent or by less coordinated independent agents.

## Differences Between Agent Team and Agent Network

The principal difference between an **agent team** $(\mathcal{A}\_{\tau})$ and an **agent network** $(\mathcal{N})$ concerns their organizational scope, immediate objective, participation structure, and interaction intensity. An agent team is primarily task-scale and is organized around a particular target task $(\tau)$, which may contain multiple subtasks $(\mathcal{T}\_{\tau})$, whereas an agent network is project-scale and supports a broader project $(P)$ containing many tasks $(\mathcal{T}\_{P})$. Agent-team membership is therefore more closely tied to meaningful participation in the target task, while network membership can include agents whose capabilities are relevant to the broader project even when they are not currently active in a particular task. Agent-team members also generally interact more intensively because they share the same immediate task objective and may repeatedly exchange intermediate results, review and critique one another's work, debate alternatives, coordinate dependencies, and jointly refine results. In an agent network, interaction can be more selective and distributed: agents working on unrelated tasks may have little or no direct communication, while particular subsets of agents may interact intensively when required.

The two structures can also differ in role and capability diversity, structural relationships, formation, and reconfiguration. Although both may contain agents with different roles and capabilities, an agent network can support broader heterogeneity across different functional domains, tools, resources, permissions, and responsibilities required by the overall project, whereas an agent team generally contains the roles and capabilities needed for its particular task. Relationships within an agent team are primarily determined by the requirements and evolving state of that task, while an agent network may additionally contain broader task dependencies, delegation relationships, supervisory relationships, communication pathways, shared-resource relationships, and temporary collaboration links across different tasks. An agent team may be dynamically formed, expanded, reduced, reorganized, or dissolved according to the needs of a particular task, while an agent network can persist across many tasks and provide a larger organizational structure from which different task-specific agent subsets are formed. Accordingly, an agent team $(\mathcal{A}\_{\tau,t})$ may operate as a localized collaborative configuration within an agent network $(\mathcal{N})$, such that $\mathcal{A}\_{\tau,t}\subseteq\mathcal{N}$, although an agent team does not necessarily require a pre-existing agent network. The distinction is therefore primarily between **task-scale, interaction-intensive collaboration** in an agent team and **project-scale organization, distributed participation, and broader agent relationships** in an agent network.
