# Agentic AI Framework: Agentic AI Notations

## Core Agentic AI Entities


| **Title**             | **Notation**                     | **Convention**                                                                                                                                                                                                                                                     |
| --------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Agentic AI            | $\mathfrak{A}$                   | Agentic AI as the overall goal-directed computational framework encompassing agents, models, instructions, tasks, context, memory, skills, tools, environments, states, actions, outputs, evaluation, and optimization.                                            |
| AI Agent              | $A$                              | LLM-supported operational agent that interprets dynamic instructions, identifies applicable requirements and subtasks, accesses context and capabilities, selects actions, invokes skills or tools, evaluates intermediate results, and performs downstream tasks. |
| Supporting Models     | $\mathcal{M}={M_1,\ldots,M_m}$   | Set of models supporting the Agentic AI, including LLMs and potentially other specialized models.                                                                                                                                                                  |
| Primary LLM           | $M_{\mathrm{LLM}}\in\mathcal{M}$ | Principal language model used for instruction interpretation, semantic matching, reasoning, generation, evaluation, and other language-centered operations.                                                                                                        |
| Agentic Configuration | $\Omega_t$                       | Runtime configuration of the Agentic AI at state or step $t$, including instructions, accessible context, memory, skills, tools, permissions, environment, and active tasks.                                                                                       |
