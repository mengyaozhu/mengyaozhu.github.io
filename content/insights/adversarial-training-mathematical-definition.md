Adversarial training is a machine learning technique designed to enhance model performance against adversarial attacks. The core idea is to train a model with both clean and adversarial examples to improve its resilience. Consider a model $f(\mathbf{x}; \theta)$ parameterized by $\theta$, where $\mathbf{x}$ represents the input data. An adversarial example $\mathbf{x}_{\text{adv}}$ is generated by adding a small perturbation $\delta$ to the original input $\mathbf{x}$ such that:

$$\mathbf{x}_{\text{adv}} = \mathbf{x} + \delta,$$

where $\delta$ is chosen to maximize the model's loss. 

The objective of adversarial training is to minimize the worst-case loss over all possible adversarial perturbations within a specified norm constraint.
